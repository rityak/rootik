# Rain visual study

Изолированный прототип визуального языка Rootik 2.0. Использует существующие компоненты и локальный CSS; исходники библиотеки, exports и зависимости не меняет.

Из корня репозитория:

```powershell
bun run dev -- --host 127.0.0.1
```

Открыть [демку](http://127.0.0.1:61000/@fs/D:/Projects/rootik/audit/rain-demo/index.html).

Фиксированные шесть строк, поиск, фильтр статуса, сортировка, выбор строки, настройки и диалог подтверждения. Переключатели вверху сравнивают solid/glass и плотность. Данные не сохраняются и не отправляются.

Этот экран проверяет визуальное направление. CSS-in-JS, SSR, стоимость бандла и миграция API здесь не реализованы.

Третья итерация материала: мягкий холодный свет без белых полос; Solid — непрозрачная матовая поверхность, Glass — просвечивающая рамка с 24px blur, широким рассеянным отражением и тонким световым краем. Табличные данные остаются на непрозрачном слое. При отсутствии backdrop-filter стекло заменяется непрозрачной поверхностью.

Знак Rootik: `assets/rootik-mark.svg` — прозрачная R с точкой, `assets/rootik-avatar.svg` — квадратный источник, `assets/rootik-avatar.png` — 1024×1024 для GitHub. Геометрия и фиолетовый цвет продолжают стиль Umiray. Знак подключён в навигацию и favicon только этой демки.
